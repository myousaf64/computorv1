Computor v1 Field Guide

One program reads a polynomial equation, moves every term to the left, reports the degree, and solves it when the degree is 2 or lower. Everything below is the program: the maths it does, the code that does it, and the traps a peer evaluator will reach for.

a·X2  +  b·X1  +  c·X0  =  0      D = b2 − 4ac
D > 0 · two real roots D = 0 · one double root D < 0 · two complex roots

How the program is shaped

Six stages, one direction

Text goes in on the left, printed lines come out on the right. Nothing loops back. Each stage below names the function that owns it and the type that leaves it.

The four cases

The maths, with nothing hidden

Reduce, read the degree, then take one of four branches. There is no fifth branch.

Step 1 — reduce

An equation is two polynomials with an = between them. Subtract the right side from the left, term by term, and the equation becomes P(X) = 0. This is the reduced form. Coefficients are added per exponent, so 5 * X^0 = 1 * X^0 collects into a single 4 * X^0.

The degree is the largest exponent whose coefficient is not zero. The word not zero is the whole trap: 0 * X^2 + 3 * X^1 = 0 is degree 1, not degree 2, and dividing by 2a with a = 0 would crash.

Step 2 — branch on the degree

DegreeShapeWhat the program prints
0c = 0c = 0 is true for every X, so Any real number is a solution. Otherwise No solution. The subject prints no degree line here.

Step 3 — the discriminant decides

Completing the square on aX² + bX + c gives a(X + b/2a)² = (b² - 4ac) / 4a. Everything hangs on the sign of the right side, which is the sign of D. That is why the discriminant is not a formula to memorise: it is the number under the square root, and a square root of a negative number is where the real line stops.

Step 4 — the square root, by hand

The subject forbids a math library function you did not write, so the file carries two square roots. int_sqrt(n) is Newton's method on whole numbers: start at n, replace the guess with (guess + n // guess) // 2, and stop when it stops falling. exact_sqrt runs it on the numerator and the denominator of a fraction; if both squares come back exactly, the root is exact and stays a fraction. Otherwise my_sqrt runs the same iteration on floats and returns a decimal.

That split is why -4 * X^0 + 1 * X^2 = 0 prints a clean -2 and 2, while X² - 2 = 0 falls back to 1.41421.

The bug worth understanding

Why the coefficients stay fractions

This is the single most likely question at the defense, and it was a real bug in the first version of this program.

Take 0.1 * X^0 + 0.3 * X^1 + 0.225 * X^2 = 0. In exact arithmetic D = 0.3² - 4 × 0.225 × 0.1 = 0.09 - 0.09 = 0, so the equation has one double root at -2/3. In binary floating point, none of 0.1, 0.3 or 0.225 is representable, and the subtraction lands just below zero.

Fraction("0.225") is exactly 9/40. Every add, subtract, multiply and divide on fractions is exact, so the cancellation lands on a true zero and the sign test disc > 0 / == 0 / < 0 is trustworthy. The program converts to float in one place only: g(), at print time.

Is Fraction a forbidden math library? No. The subject forbids a math function you did not implement, and names addition, subtraction, multiplication and division as allowed. Fraction is a number type that performs exactly those four operations on a numerator and a denominator. No root, no power, no logarithm comes from a library: int_sqrt and my_sqrt are in the file.

Every function

Code walkthrough

The whole program is one file, about 340 lines with the comments. Open a function to read the source and what it is for. The first three are open, because the parser is where nearly all the difficulty lives.

The scanner chars to one term

Three small readers walk the string from left to right. _skip eats blanks, _number reads 12, .5 or 1e-10 into an exact Fraction, and _term reads one whole term.

Each of the coefficient, the * and the ^n is optional, which is what makes free form entry work: X is 1 * X^1 and a bare 5 is 5 * X^0. When nothing matches, _term raises instead of returning nothing, so a stray Y can never be dropped in silence.

def _skip(s, i):
    while i < len(s) and s[i] in ' \t':
        i += 1
    return i

def _number(s, i):
    """Return (Fraction, next index). Return (None, i) when no number is at i."""
    start = i
    while i < len(s) and s[i] in DIGITS:
        i += 1
    if i < len(s) and s[i] == '.':
        i += 1
        while i < len(s) and s[i] in DIGITS:
            i += 1
    if i == start:
        return None, start
    if s[start:i] == '.':
        raise ParseError('a lone "." is not a number')
    end = i
    if end < len(s) and s[end] in 'eE':
        j = end + 1
        if j < len(s) and s[j] in '+-':
            j += 1
        k = j
        while j < len(s) and s[j] in DIGITS:
            j += 1
        if j > k:
            end = j
    return Fraction(s[start:end]), end

def _term(s, i):
    """Parse one term. Return (coefficient, exponent, next index)."""
    coeff, i = _number(s, i)
    i = _skip(s, i)
    star = i < len(s) and s[i] == '*'
    if star:
        i = _skip(s, i + 1)
    if i < len(s) and s[i] in 'Xx':
        i = _skip(s, i + 1)
        exponent = 1
        if i < len(s) and s[i] == '^':
            i = _skip(s, i + 1)
            value, i = _number(s, i)
            if value is None or value < 0 or value.denominator != 1:
                raise ParseError('an exponent must be a whole number, 0 or more')
            exponent = int(value)
        return (Fraction(1) if coeff is None else coeff), exponent, i
    if star:
        raise ParseError('a "*" must be followed by X')
    if coeff is None:
        if i >= len(s):
            raise ParseError('a term is missing at the end of a side')
        raise ParseError('unexpected symbol "%s"' % s[i])
    return coeff, 0, i
parse_side, parse terms to coefficients

parse_side loops over terms, and demands a + or a - between two of them. Anything else is a ParseError, which is how leftover text is caught.

parse splits on =, insists on exactly one, then subtracts every right coefficient from the matching left one. That subtraction is the reduction: after it, the equation is P(X) = 0. It also returns the two raw sides, which --verbose prints.

def parse_side(s):
    """Return {exponent: Fraction} for one side of the equation."""
    i = _skip(s, 0)
    if i >= len(s):
        raise ParseError('one side of the equation is empty')
    sign = 1
    if s[i] in '+-':
        sign = -1 if s[i] == '-' else 1
        i = _skip(s, i + 1)
    coeffs = {}
    while True:
        coeff, exponent, i = _term(s, i)
        coeffs[exponent] = coeffs.get(exponent, Fraction(0)) + sign * coeff
        i = _skip(s, i)
        if i >= len(s):
            return coeffs
        if s[i] not in '+-':
            raise ParseError('unexpected symbol "%s" - put a "+" or a "-" '
                             'between two terms' % s[i])
        sign = -1 if s[i] == '-' else 1
        i = _skip(s, i + 1)

def parse(equation):
    """Return (reduced coefficients, left coefficients, right coefficients)."""
    sides = equation.split('=')
    if len(sides) != 2:
        raise ParseError('an equation must have exactly one "="')
    left = parse_side(sides[0])
    right = parse_side(sides[1])
    coeffs = dict(left)
    for exponent, coeff in right.items():
        coeffs[exponent] = coeffs.get(exponent, Fraction(0)) - coeff
    return coeffs, left, right
The square roots no math library

int_sqrt is Newton's method on whole numbers: the guess falls until it stops falling. exact_sqrt runs it on the numerator and the denominator, and returns a Fraction only when both come back as perfect squares. my_sqrt runs the same iteration on floats for the irrational case and stops as soon as the guess repeats.

root_of picks the exact one when it exists. That is why √16 stays 4 and never becomes 4.000000000000001.

def int_sqrt(n):
    """Return the integer square root of n by Newton's method."""
    if n < 2:
        return n
    x, y = n, (n + 1) // 2
    while y < x:
        x, y = y, (y + n // y) // 2
    return x

def exact_sqrt(value):
    """Return the exact square root of a Fraction, or None when it is irrational."""
    if value < 0:
        return None
    top, bottom = int_sqrt(value.numerator), int_sqrt(value.denominator)
    if top * top == value.numerator and bottom * bottom == value.denominator:
        return Fraction(top, bottom)
    return None

def my_sqrt(value):
    """Return the square root of a number by Newton's method."""
    x = float(value)
    if x <= 0:
        return 0.0
    guess = x if x >= 1 else 1.0
    for _ in range(80):
        better = (guess + x / guess) / 2
        if better == guess:
            break
        guess = better
    return guess

def root_of(value):
    """Return the exact square root when it exists, else the float one."""
    exact = exact_sqrt(value)
    return exact if exact is not None else my_sqrt(value)
Formatting %g, six digits

g is the only place a Fraction becomes a float. Adding 0.0 first turns -0.0 into 0.0, so a zero root never prints as -0.

reduced_form prints every exponent from 0 up to the degree, including the zero ones, because the subject's own example prints 0 * X^2. The degree is the largest exponent whose coefficient is not zero.

def g(x):
    """Format a number like the subject examples. Never print a negative zero."""
    return '%g' % (float(x) + 0.0)

def show(value, opts):
    """Format a solution. Add the irreducible fraction when --fractions is on."""
    if opts['fractions'] and isinstance(value, Fraction):
        return str(value) if value.denominator == 1 else '%s (%s)' % (value, g(value))
    return g(value)

def reduced_form(coeffs):
    """Return (the reduced form text, the degree)."""
    degree = max((d for d, c in coeffs.items() if c != 0), default=0)
    parts = ['%s * X^0' % g(coeffs.get(0, Fraction(0)))]
    for d in range(1, degree + 1):
        c = coeffs.get(d, Fraction(0))
        parts.append('%s %s * X^%d' % ('+' if c >= 0 else '-', g(abs(c)), d))
    return ' '.join(parts) + ' = 0', degree
solve the four branches

Degree 0 prints no degree line, because the subject's examples do not. Degree 1 divides -c by b, which is safe: if b were zero the degree would not be 1. Degree above 2 refuses.

For degree 2 the discriminant is built from Fraction values, so disc > 0, disc == 0 and disc < 0 are exact tests, not float guesses. Every [steps] line is behind the flag, so the default output is untouched.

def solve(coeffs, degree, out, opts):
    a = coeffs.get(2, Fraction(0))
    b = coeffs.get(1, Fraction(0))
    c = coeffs.get(0, Fraction(0))
    roots = []
    if degree == 0:
        # The subject prints no degree line for a degree 0 equation.
        out('Any real number is a solution.' if c == 0 else 'No solution.')
        return roots
    out('Polynomial degree: %d' % degree)
    if degree > 2:
        out("The polynomial degree is strictly greater than 2, I can't solve.")
        return roots
    if degree == 1:
        if opts['steps']:
            out('[steps] b = %s, c = %s' % (b, c))
            out('[steps] b * X + c = 0, so X = -c / b = -(%s) / (%s)' % (c, b))
        root = -c / b
        roots = [root]
        out('The solution is:')
        out(show(root, opts))
        return roots
    disc = b * b - 4 * a * c
    if opts['steps']:
        out('[steps] a = %s, b = %s, c = %s' % (a, b, c))
        out('[steps] discriminant = b^2 - 4*a*c = (%s)^2 - 4*(%s)*(%s) = %s'
            % (b, a, c, disc))
        out('[steps] the discriminant is exact, so its sign is exact')
    if disc > 0:
        r = root_of(disc)
        if opts['steps']:
            out('[steps] sqrt(%s) = %s%s' % (disc, r,
                                             '' if isinstance(r, Fraction) else ' (Newton)'))
            out('[steps] X = (-b -+ sqrt(D)) / (2*a), 2*a = %s' % (2 * a))
        roots = [(-b - r) / (2 * a), (-b + r) / (2 * a)]
        out('Discriminant is strictly positive, the two solutions are:')
        out(show(roots[0], opts))
        out(show(roots[1], opts))
    elif disc == 0:
        if opts['steps']:
            out('[steps] X = -b / (2*a) = -(%s) / (%s)' % (b, 2 * a))
        roots = [-b / (2 * a)]
        out('Discriminant is zero, the solution is:')
        out(show(roots[0], opts))
    else:
        real = -b / (2 * a)
        r = root_of(-disc)
        imaginary = r / (2 * a)
        if opts['steps']:
            out('[steps] sqrt(-D) = sqrt(%s) = %s' % (-disc, r))
            out('[steps] X = -b / (2*a) -+ i * sqrt(-D) / (2*a)')
        roots = [complex(float(real), float(abs(imaginary))),
                 complex(float(real), -float(abs(imaginary)))]
        out('Discriminant is strictly negative, the two complex solutions are:')
        out('%s + %si' % (show(real, opts), show(abs(imaginary), opts)))
        out('%s - %si' % (show(real, opts), show(abs(imaginary), opts)))
    return roots
The two printers bonus output

coefficient_table is --verbose: one row per exponent, left, right, and the difference, so a reader can check the reduction by hand.

plot is --plot: a fixed 61 by 21 character grid. It maps each sampled y to a row, draws the x axis as dashes, and puts an O at each real root.

def coefficient_table(coeffs, left, right, out):
    """Print every collected term per side, so a reader can check the reduction."""
    out('Coefficients:')
    out('  X^n | left       | right      | left - right')
    for d in sorted(set(left) | set(right) | set(coeffs)):
        out('  %3d | %10s | %10s | %s' % (
            d, left.get(d, Fraction(0)), right.get(d, Fraction(0)),
            coeffs.get(d, Fraction(0))))

def plot(a, b, c, roots, out):
    """Draw the curve with ASCII characters. O marks a root."""
    # ponytail: fixed 61x21 grid, enough to read the shape at a defense.
    width, height = 61, 21
    xs = [float(r) for r in roots if not isinstance(r, complex)]
    if xs:
        lo, hi = min(xs), max(xs)
        pad = max(hi - lo, 1.0)
        lo, hi = lo - pad, hi + pad
    else:
        lo, hi = -5.0, 5.0
    a, b, c = float(a), float(b), float(c)
    ys = [a * x * x + b * x + c
          for x in (lo + (hi - lo) * i / (width - 1) for i in range(width))]
    top, bottom = max(ys), min(ys)
    if top == bottom:
        top, bottom = top + 1.0, bottom - 1.0

    def row(y):
        r = int((top - y) / (top - bottom) * (height - 1) + 0.5)
        return min(max(r, 0), height - 1)

    def col(x):
        return min(max(int((x - lo) / (hi - lo) * (width - 1) + 0.5), 0), width - 1)

    grid = [[' '] * width for _ in range(height)]
    axis = row(0.0) if bottom <= 0 <= top else None
    if axis is not None:
        grid[axis] = ['-'] * width
    for i, y in enumerate(ys):
        grid[row(y)][i] = '*'
    for x in xs:
        if lo <= x <= hi:
            grid[axis if axis is not None else height - 1][col(x)] = 'O'
    out('Plot: x from %s to %s, y from %s to %s, O marks a root'
        % (g(lo), g(hi), g(bottom), g(top)))
    for line in grid:
        out('  ' + ''.join(line).rstrip())
run, main wiring

run is the whole program in six lines, and takes an out function so the tests can capture the printed lines without touching stdout.

main reads the flags, falls back to STDIN when no equation argument is present, and catches ParseError to print error: <reason> on stderr with exit status 1. A leading - followed by a digit is an equation, not an option, so "-4 * X^0 + 1 * X^2 = 0" still works.

def run(equation, out=print, opts=None):
    opts = DEFAULTS if opts is None else opts
    coeffs, left, right = parse(equation)
    if opts['verbose']:
        coefficient_table(coeffs, left, right, out)
    form, degree = reduced_form(coeffs)
    out('Reduced form: %s' % form)
    roots = solve(coeffs, degree, out, opts)
    if opts['plot']:
        plot(coeffs.get(2, Fraction(0)), coeffs.get(1, Fraction(0)),
             coeffs.get(0, Fraction(0)), roots, out)


FLAGS = {'--steps': 'steps', '--fractions': 'fractions',
         '--verbose': 'verbose', '--plot': 'plot'}
DEFAULTS = {name: False for name in FLAGS.values()}

def main(argv):
    opts = dict(DEFAULTS)
    args = []
    for arg in argv:
        if arg in FLAGS:
            opts[FLAGS[arg]] = True
        elif arg in ('-h', '--help'):
            print(USAGE)
            return 0
        elif arg[:1] == '-' and len(arg) > 1 and arg[1] not in DIGITS + '.':
            print('error: unknown option "%s"' % arg, file=sys.stderr)
            print(USAGE, file=sys.stderr)
            return 1
        else:
            args.append(arg)
    if len(args) > 1:
        print('error: give exactly one equation', file=sys.stderr)
        return 1
    equation = args[0] if args else sys.stdin.readline().strip()
    if not equation:
        print(USAGE, file=sys.stderr)
        return 1
    try:
        run(equation, opts=opts)
    except ParseError as error:
        print('error: %s' % error, file=sys.stderr)
        return 1
    return 0


if __name__ == '__main__':
    sys.exit(main(sys.argv[1:]))

The complete file

#!/usr/bin/env python3
"""Computor v1 - solve a polynomial equation of degree 2 or lower.

The arithmetic is exact. Coefficients, the discriminant and the roots stay
Fraction values, so a discriminant that is truly zero reads as zero and not as
a small negative float. No math library computes a root: int_sqrt and my_sqrt
are hand-written Newton iterations, as the subject allows only the four
operations that you implement yourself.

Mandatory output is byte-identical to the subject examples. Every bonus is
behind a flag, so the default run never changes.
"""
import sys
from fractions import Fraction

USAGE = """usage: computor [options] "<equation>"

Read the equation from the argument. Read it from STDIN when no argument
is present.

options:
  --steps      Print the intermediate calculation.
  --fractions  Print each solution as an irreducible fraction.
  --verbose    Print the coefficient table of the two sides.
  --plot       Draw the curve with ASCII characters.
  -h, --help   Print this text."""

DIGITS = '0123456789'


class ParseError(Exception):
    """The input is not a valid equation."""


# --------------------------------------------------------------------------
# parsing
#
# One grammar reads the canonical form and the free form:
#
#   side := term (('+' | '-') term)*
#   term := [number] ['*'] [X ['^' whole number]]
#
# The scanner consumes the side from left to right. Any symbol that the
# grammar does not accept raises a ParseError, so no term is dropped in
# silence.
# --------------------------------------------------------------------------

def _skip(s, i):
    while i < len(s) and s[i] in ' \t':
        i += 1
    return i


def _number(s, i):
    """Return (Fraction, next index). Return (None, i) when no number is at i."""
    start = i
    while i < len(s) and s[i] in DIGITS:
        i += 1
    if i < len(s) and s[i] == '.':
        i += 1
        while i < len(s) and s[i] in DIGITS:
            i += 1
    if i == start:
        return None, start
    if s[start:i] == '.':
        raise ParseError('a lone "." is not a number')
    end = i
    if end < len(s) and s[end] in 'eE':
        j = end + 1
        if j < len(s) and s[j] in '+-':
            j += 1
        k = j
        while j < len(s) and s[j] in DIGITS:
            j += 1
        if j > k:
            end = j
    return Fraction(s[start:end]), end


def _term(s, i):
    """Parse one term. Return (coefficient, exponent, next index)."""
    coeff, i = _number(s, i)
    i = _skip(s, i)
    star = i < len(s) and s[i] == '*'
    if star:
        i = _skip(s, i + 1)
    if i < len(s) and s[i] in 'Xx':
        i = _skip(s, i + 1)
        exponent = 1
        if i < len(s) and s[i] == '^':
            i = _skip(s, i + 1)
            value, i = _number(s, i)
            if value is None or value < 0 or value.denominator != 1:
                raise ParseError('an exponent must be a whole number, 0 or more')
            exponent = int(value)
        return (Fraction(1) if coeff is None else coeff), exponent, i
    if star:
        raise ParseError('a "*" must be followed by X')
    if coeff is None:
        if i >= len(s):
            raise ParseError('a term is missing at the end of a side')
        raise ParseError('unexpected symbol "%s"' % s[i])
    return coeff, 0, i


def parse_side(s):
    """Return {exponent: Fraction} for one side of the equation."""
    i = _skip(s, 0)
    if i >= len(s):
        raise ParseError('one side of the equation is empty')
    sign = 1
    if s[i] in '+-':
        sign = -1 if s[i] == '-' else 1
        i = _skip(s, i + 1)
    coeffs = {}
    while True:
        coeff, exponent, i = _term(s, i)
        coeffs[exponent] = coeffs.get(exponent, Fraction(0)) + sign * coeff
        i = _skip(s, i)
        if i >= len(s):
            return coeffs
        if s[i] not in '+-':
            raise ParseError('unexpected symbol "%s" - put a "+" or a "-" '
                             'between two terms' % s[i])
        sign = -1 if s[i] == '-' else 1
        i = _skip(s, i + 1)


def parse(equation):
    """Return (reduced coefficients, left coefficients, right coefficients)."""
    sides = equation.split('=')
    if len(sides) != 2:
        raise ParseError('an equation must have exactly one "="')
    left = parse_side(sides[0])
    right = parse_side(sides[1])
    coeffs = dict(left)
    for exponent, coeff in right.items():
        coeffs[exponent] = coeffs.get(exponent, Fraction(0)) - coeff
    return coeffs, left, right


# --------------------------------------------------------------------------
# arithmetic without a math library
# --------------------------------------------------------------------------

def int_sqrt(n):
    """Return the integer square root of n by Newton's method."""
    if n < 2:
        return n
    x, y = n, (n + 1) // 2
    while y < x:
        x, y = y, (y + n // y) // 2
    return x


def exact_sqrt(value):
    """Return the exact square root of a Fraction, or None when it is irrational."""
    if value < 0:
        return None
    top, bottom = int_sqrt(value.numerator), int_sqrt(value.denominator)
    if top * top == value.numerator and bottom * bottom == value.denominator:
        return Fraction(top, bottom)
    return None


def my_sqrt(value):
    """Return the square root of a number by Newton's method."""
    x = float(value)
    if x <= 0:
        return 0.0
    guess = x if x >= 1 else 1.0
    for _ in range(80):
        better = (guess + x / guess) / 2
        if better == guess:
            break
        guess = better
    return guess


def root_of(value):
    """Return the exact square root when it exists, else the float one."""
    exact = exact_sqrt(value)
    return exact if exact is not None else my_sqrt(value)


# --------------------------------------------------------------------------
# formatting
# --------------------------------------------------------------------------

def g(x):
    """Format a number like the subject examples. Never print a negative zero."""
    return '%g' % (float(x) + 0.0)


def show(value, opts):
    """Format a solution. Add the irreducible fraction when --fractions is on."""
    if opts['fractions'] and isinstance(value, Fraction):
        return str(value) if value.denominator == 1 else '%s (%s)' % (value, g(value))
    return g(value)


def reduced_form(coeffs):
    """Return (the reduced form text, the degree)."""
    degree = max((d for d, c in coeffs.items() if c != 0), default=0)
    parts = ['%s * X^0' % g(coeffs.get(0, Fraction(0)))]
    for d in range(1, degree + 1):
        c = coeffs.get(d, Fraction(0))
        parts.append('%s %s * X^%d' % ('+' if c >= 0 else '-', g(abs(c)), d))
    return ' '.join(parts) + ' = 0', degree


def coefficient_table(coeffs, left, right, out):
    """Print every collected term per side, so a reader can check the reduction."""
    out('Coefficients:')
    out('  X^n | left       | right      | left - right')
    for d in sorted(set(left) | set(right) | set(coeffs)):
        out('  %3d | %10s | %10s | %s' % (
            d, left.get(d, Fraction(0)), right.get(d, Fraction(0)),
            coeffs.get(d, Fraction(0))))


def plot(a, b, c, roots, out):
    """Draw the curve with ASCII characters. O marks a root."""
    # ponytail: fixed 61x21 grid, enough to read the shape at a defense.
    width, height = 61, 21
    xs = [float(r) for r in roots if not isinstance(r, complex)]
    if xs:
        lo, hi = min(xs), max(xs)
        pad = max(hi - lo, 1.0)
        lo, hi = lo - pad, hi + pad
    else:
        lo, hi = -5.0, 5.0
    a, b, c = float(a), float(b), float(c)
    ys = [a * x * x + b * x + c
          for x in (lo + (hi - lo) * i / (width - 1) for i in range(width))]
    top, bottom = max(ys), min(ys)
    if top == bottom:
        top, bottom = top + 1.0, bottom - 1.0

    def row(y):
        r = int((top - y) / (top - bottom) * (height - 1) + 0.5)
        return min(max(r, 0), height - 1)

    def col(x):
        return min(max(int((x - lo) / (hi - lo) * (width - 1) + 0.5), 0), width - 1)

    grid = [[' '] * width for _ in range(height)]
    axis = row(0.0) if bottom <= 0 <= top else None
    if axis is not None:
        grid[axis] = ['-'] * width
    for i, y in enumerate(ys):
        grid[row(y)][i] = '*'
    for x in xs:
        if lo <= x <= hi:
            grid[axis if axis is not None else height - 1][col(x)] = 'O'
    out('Plot: x from %s to %s, y from %s to %s, O marks a root'
        % (g(lo), g(hi), g(bottom), g(top)))
    for line in grid:
        out('  ' + ''.join(line).rstrip())

# solving

def solve(coeffs, degree, out, opts):
    a = coeffs.get(2, Fraction(0))
    b = coeffs.get(1, Fraction(0))
    c = coeffs.get(0, Fraction(0))
    roots = []
    if degree == 0:
        # The subject prints no degree line for a degree 0 equation.
        out('Any real number is a solution.' if c == 0 else 'No solution.')
        return roots
    out('Polynomial degree: %d' % degree)
    if degree > 2:
        out("The polynomial degree is strictly greater than 2, I can't solve.")
        return roots
    if degree == 1:
        if opts['steps']:
            out('[steps] b = %s, c = %s' % (b, c))
            out('[steps] b * X + c = 0, so X = -c / b = -(%s) / (%s)' % (c, b))
        root = -c / b
        roots = [root]
        out('The solution is:')
        out(show(root, opts))
        return roots
    disc = b * b - 4 * a * c
    if opts['steps']:
        out('[steps] a = %s, b = %s, c = %s' % (a, b, c))
        out('[steps] discriminant = b^2 - 4*a*c = (%s)^2 - 4*(%s)*(%s) = %s'
            % (b, a, c, disc))
        out('[steps] the discriminant is exact, so its sign is exact')
    if disc > 0:
        r = root_of(disc)
        if opts['steps']:
            out('[steps] sqrt(%s) = %s%s' % (disc, r,
                                             '' if isinstance(r, Fraction) else ' (Newton)'))
            out('[steps] X = (-b -+ sqrt(D)) / (2*a), 2*a = %s' % (2 * a))
        roots = [(-b - r) / (2 * a), (-b + r) / (2 * a)]
        out('Discriminant is strictly positive, the two solutions are:')
        out(show(roots[0], opts))
        out(show(roots[1], opts))
    elif disc == 0:
        if opts['steps']:
            out('[steps] X = -b / (2*a) = -(%s) / (%s)' % (b, 2 * a))
        roots = [-b / (2 * a)]
        out('Discriminant is zero, the solution is:')
        out(show(roots[0], opts))
    else:
        real = -b / (2 * a)
        r = root_of(-disc)
        imaginary = r / (2 * a)
        if opts['steps']:
            out('[steps] sqrt(-D) = sqrt(%s) = %s' % (-disc, r))
            out('[steps] X = -b / (2*a) -+ i * sqrt(-D) / (2*a)')
        roots = [complex(float(real), float(abs(imaginary))),
                 complex(float(real), -float(abs(imaginary)))]
        out('Discriminant is strictly negative, the two complex solutions are:')
        out('%s + %si' % (show(real, opts), show(abs(imaginary), opts)))
        out('%s - %si' % (show(real, opts), show(abs(imaginary), opts)))
    return roots


def run(equation, out=print, opts=None):
    opts = DEFAULTS if opts is None else opts
    coeffs, left, right = parse(equation)
    if opts['verbose']:
        coefficient_table(coeffs, left, right, out)
    form, degree = reduced_form(coeffs)
    out('Reduced form: %s' % form)
    roots = solve(coeffs, degree, out, opts)
    if opts['plot']:
        plot(coeffs.get(2, Fraction(0)), coeffs.get(1, Fraction(0)),
             coeffs.get(0, Fraction(0)), roots, out)

    args = []
    for arg in argv:
        if arg in FLAGS:
            opts[FLAGS[arg]] = True
        elif arg in ('-h', '--help'):
            print(USAGE)
            return 0
        elif arg[:1] == '-' and len(arg) > 1 and arg[1] not in DIGITS + '.':
            print('error: unknown option "%s"' % arg, file=sys.stderr)

            return 1
        else:
            args.append(arg)
    if len(args) > 1:

        return 1
    equation = args[0] if args else sys.stdin.readline().strip()

Answers, short

Defense notes

The questions a peer evaluator asks, and the shortest true answer to each.

Where is the discriminant, and why that formula?
In solve(): disc = b*b - 4*a*c. It is what is left under the square root after completing the square, so its sign decides whether the square root is real. Nothing else in the quadratic formula can change the number of real roots.
Show me that you did not use a math library.
The file imports sys and fractions, nothing else. int_sqrt and my_sqrt are Newton iterations written in the file. Run grep import computor.py.
Is Fraction cheating?
It is a number type that adds, subtracts, multiplies and divides — the four operations the subject allows. It computes no root and no power. Without it the discriminant sign is wrong for decimal coefficients, which is a correctness bug, not a shortcut.
What happens with 0 * X^2 + 3 * X^1 = 0?
Degree 1, not 2. reduced_form() takes the largest exponent whose coefficient is not zero. Treating it as degree 2 would divide by 2a = 0.
Why print no degree line for a degree 0 equation?
Because the subject's own examples do not print one. Match the subject output byte for byte; the six worked examples are asserted in test_computor.py.
Why does 0.905239 have six digits?
g() formats with %g, which is six significant digits and drops trailing zeros. The subject screenshots use the same format.
What does your program do with garbage input?
It raises ParseError, prints error: <reason> on stderr, and exits 1. No traceback. The scanner rejects any character the grammar does not accept, so no term is ever dropped in silence.
How do you know the complex roots are right?
Substitute them back. For 1 + 2X + 5X² the roots are -0.2 ± 0.4i; their sum is -b/a = -0.4 and their product is c/a = 0.2. Both hold.
Why Newton for the square root?
It doubles the correct digits each pass, needs only divide and add, and stops when the guess stops moving. On whole numbers the same iteration is exact, which is how √16 = 4 stays a fraction instead of becoming 4.000000000000001.
Where is your Makefile?
The subject asks for one only for a compiled language. This is Python; the entry point is python3 computor.py.
